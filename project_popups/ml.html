Overview

This project studies one-day-ahead AAPL forecasting with a dual setup: 3-class direction classification (Down / Flat / Up) and return regression. The final dataset includes 1,488 daily observations (2019-2024) and 133 engineered features spanning technical, fundamental, ETF, and macroeconomic signals.

Modeling Setup
  • Classification models: Logistic Regression, SVM-RBF, MLP, Random Forest, XGBoost.
  • Regression models: Linear Regression, MLP Regressor, Random Forest Regressor, XGBoost Regressor.
  • Temporal split: first 85% train (1,265 rows), final 15% test (223 rows) to prevent lookahead leakage.
  • Validation strategy emphasizes time-aware evaluation rather than random k-fold cross-validation.
Key Findings

Ensembles Lead At This Data Scale

XGBoost and Random Forest outperform linear baselines, and XGBoost is strongest for both classification and regression in this dataset regime.

Time-Aware Validation Is Mandatory

Random k-fold validation inflates confidence; TimeSeriesSplit and strict temporal holdout give more realistic performance estimates for finance tasks.

Feature Engineering Drives Lift

Momentum ratios, lagged returns/direction, and volatility features combine with macro context to carry most of the predictive signal.

Feature Signal Summary
  • Top 10 features account for 53.8% of total model importance.
  • Momentum indicators (price-to-EMA, RSI, MACD) form the strongest signal cluster.
  • Lagged direction and lagged return features are consistently high-ranked temporal predictors.
  • Volatility and macro context matter: Bollinger %B, ATR, and VIX appear among top-ranked inputs.
